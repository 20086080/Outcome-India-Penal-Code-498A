# Outcome-India-Penal-Code-498A
## Project Overview

This Power BI dashboard analyses trends in crimes against women in India using NCRB data.

## Problem Statement

Understanding crime trends, conviction rates and judicial backlogs can support policy analysis and public awareness.

## Tools Used

- Power BI
- Excel
- DAX

## Data Source

National Crime Records Bureau (NCRB)

## Business Questions Answered

- Which states report the highest number of crimes?
- How have crime trends changed over time?
- What are the conviction rates?
- How large is the trial backlog?
